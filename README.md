# Свой Маркет — тайкун: симулятор маркетплейса 🏙️💰

Глубокая пошаговая игра в духе Game Dev Tycoon: вы управляете маркетплейсом, каждый ход — неделя стратегических решений с риском и азартом.

## 🎮 Играть

**https://egzy164rus.github.io/tycoon/**

## 🕹 Что в игре

- **Экран приветствия** с выбором сложности (Спокойный / Стандарт / Титан) и названием компании
- **5 экранов управления:** Кабинет, Команда, Исследования, Проекты, Рынок
- **Команда:** наём, обучение, мораль, премии и тимбилдинг
- **12 технологий** в трёх ветках и **8 многонедельных проектов**
- **Конкуренты:** агрессивные атаки за долю рынка и волатильность спроса
- **Азарт:** кредиты с еженедельными платежами и рискованные ставки с реальными шансами
- **17 событий с выбором**, включая решения «50/50» с видимыми шансами
- **Цели с дедлайнами** — просроченные награды сгорают
- **14 достижений** 🏅 и **хроники компании** — статистика, рекорды и настроения конкурентов
- **Звуковые эффекты** 🔊 (синтез через WebAudio, с выключателем) и анимированные финансы
- **Победа и поражение:** международная империя (22% доли, 250 000 ₽) или банкротство (3 недели в минусе)

## 📲 Установка как приложение (PWA)

Игра работает офлайн после первого запуска и устанавливается на рабочий стол.

- **Android (Chrome):** меню **⋮** → **Установить приложение**
- **iPhone (Safari):** **Поделиться** → **На экран «Домой»** → **Добавить**

Подробнее: [PWA-IPHONE.md](PWA-IPHONE.md)

## 💾 Сохранения

Прогресс хранится в `localStorage` браузера и привязан к адресу сайта.

## 🗂 Структура проекта

- `index.html` — точка входа
- `game.js` — правила игры: экономика, технологии, проекты, события, кредиты
- `engine.js` — мини-движок (состояние, действия, автосохранение)
- `main.js` — запуск игры и регистрация service worker
- `sw.js` — офлайн-кэш PWA (стратегия «сеть в приоритете»)
- `manifest.webmanifest` — манифест PWA
- `.github/workflows/pages.yml` — автодеплой на GitHub Pages

## 🚀 Публикация

Каждый push в ветку `main` автоматически публикует сайт через GitHub Actions.
После изменения файлов увеличивайте версию `CACHE_NAME` в `sw.js`, чтобы устройства обновили кэш.
