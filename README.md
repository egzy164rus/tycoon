## 📲 Установка как приложение (PWA)

Игра — полноценное PWA-приложение: работает без сети после первого запуска, устанавливается на рабочий стол.

**Android (Chrome):**
1. Откройте сайт в Chrome.
2. Меню **⋮** → **Установить приложение** (или «Добавить на главный экран»).
3. Запустите с нового значка — после первого запуска игра работает офлайн.

**iPhone (Safari):**
1. Откройте сайт в **Safari** (не во встроенном браузере).
2. **Поделиться** → **На экран «Домой»** → **Добавить**.
3. Запустите приложение с иконки хотя бы один раз с интернетом — дальше игра доступна офлайн.

Подробнее: [PWA-IPHONE.md](PWA-IPHONE.md)

## 💾 Сохранения

Прогресс хранится в `localStorage` браузера и привязан к адресу сайта.

## 🗂 Структура проекта

- `index.html` — точка входа
- `game.js` — игровая логика и интерфейс
- `engine.js` — мини-движок (состояние, события, сохранение)
- `main.js` — запуск игры и регистрация service worker
- `sw.js` — service worker (офлайн-кэш)
- `manifest.webmanifest` — манифест PWA
- `assets/` — иконки и фотографии товаров
- `.github/workflows/pages.yml` — автодеплой на GitHub Pages при пуше в `main`

## 🚀 Публикация

Каждый push в ветку `main` автоматически публикует сайт через GitHub Actions (GitHub Pages).
После изменения файлов сайта увеличивайте версию `CACHE_NAME` в `sw.js`, чтобы устройства обновили кэш.
