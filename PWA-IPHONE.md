# PWA на iPhone — «Свой Маркет»

В проект добавлены `manifest.webmanifest`, service worker `sw.js`, регистрация service worker в `main.js` и иконки для iOS/Android. Service worker заранее кэширует игру, стили, скрипты, фотографии и значки для последующего запуска без сети.

## Важно: нужен HTTPS-хостинг

PWA нельзя установить прямо из ZIP или локального HTML-файла: установка и service worker требуют сайта на HTTPS (исключение — `localhost` для разработки). ZIP `market-tycoon-pwa.zip` — готовая папка сайта для публикации на статическом HTTPS-хостинге. Корневой `index.html` в архиве уже ссылается на относительные пути, поэтому публикация в корне сайта или GitHub Pages в подпапке поддерживается.

## Установка на iPhone

1. Опубликуйте содержимое ZIP на HTTPS-хостинге.
2. Откройте адрес сайта в **Safari**, не во встроенном браузере другого приложения.
3. Нажмите **Поделиться** → **На экран «Домой»** → **Добавить**. Если отображается настройка «Открывать как веб-приложение», оставьте её включённой.
4. Запустите приложение с нового значка хотя бы один раз при подключённом интернете. После установки и первого кэширования оболочка игры и локальные фотографии будут доступны без сети.

Прогресс игры хранится в `localStorage` браузера и привязан к адресу сайта. Если домен или схема адреса изменятся, это будет отдельное сохранение.

## Обновление

После изменений пересоберите архив командой `python3 build_pwa.py`. Если меняются файлы сайта, увеличьте версию `CACHE_NAME` в `sw.js`, чтобы устройства скачали новый кэш.
